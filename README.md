# TextMeter

**TextMeter** — приложение на FastAPI с веб-интерфейсом для подсчёта слов и символов, оценки времени чтения и поиска наиболее частых слов.

## Установка

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Установите зависимости приложения и тестов:

```bash
python -m pip install -r requirements-dev.txt
```

## Настройки

Создайте `.env` на основе `.env.example`:

```dotenv
APP_VERSION=1.0.0
READING_SPEED_WPM=200
LOG_LEVEL=INFO
```

- `APP_VERSION` — версия приложения.
- `READING_SPEED_WPM` — скорость чтения: целое положительное число.
- `LOG_LEVEL` — уровень логирования: `DEBUG`, `INFO`, `WARNING`, `ERROR` или `CRITICAL`.

Это также значения по умолчанию. Переменные окружения имеют приоритет над `.env`. После изменения настроек перезапустите приложение.

Настоящий `.env` исключён через `.gitignore`. Пароли и токены в репозиторий не добавляются.

## Запуск

Обычный запуск:

```bash
python -m uvicorn app_final:app
```

Для разработки с автоматическим перезапуском:

```bash
python -m uvicorn app_final:app --reload
```

После запуска откройте:

- Веб-интерфейс: http://127.0.0.1:8000/
- Документация API: http://127.0.0.1:8000/docs
- Проверка работоспособности: http://127.0.0.1:8000/health
- Версия приложения: http://127.0.0.1:8000/version

Для остановки сервера нажмите `Ctrl+C`.

## Использование

1. Откройте веб-интерфейс через запущенное приложение.
2. Введите текст.
3. Укажите количество популярных слов от 1 до 20.
4. Нажмите «Анализировать».

Страница покажет количество слов и символов, приблизительное время чтения и таблицу частот. Открывать `index.html` напрямую не нужно.

## Маршруты API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/` | Веб-интерфейс |
| GET | `/health` | Проверка работоспособности |
| GET | `/version` | Версия приложения |
| POST | `/text/stats` | Количество слов и символов |
| POST | `/text/reading-time` | Приблизительное время чтения |
| POST | `/text/top-words?limit=5` | Наиболее частые слова |

Для POST-запросов передайте JSON:

```json
{
  "text": "Привет, мир!"
}
```

Параметр `limit` принимает значения от 1 до 20, по умолчанию — 5. Запросы также можно отправлять через `/docs`.

## Правила анализа

- Словом считается последовательность букв или цифр.
- Пунктуация и подчёркивания разделяют слова.
- При частотном анализе регистр не учитывается.
- Разные формы слов не объединяются.
- Пустой текст и текст только из пробельных символов отклоняются.
- Поле `characters_without_spaces` исключает пробелы, табуляции и переносы строк.
- Время чтения рассчитывается по настройке `READING_SPEED_WPM` и является приблизительным.

Текст и результаты не сохраняются. База данных и внешние API не используются.

## Тестирование

```bash
python -m pytest -v
```

Тесты проверяют выдачу HTML-страницы, маршруты API, расчёты и обработку некорректных данных. Запускать сервер отдельно не нужно.

Работу кнопки и отображение результатов в браузере проверяют вручную.

## GitHub Actions

Workflow в `.github/workflows/ci.yml` запускает тесты при `push` и `pull_request`.

После успешной проверки создаётся artifact `textmeter-app` с кодом, HTML-страницей, тестами, зависимостями, README и `.env.example`. Настоящий `.env` в artifact не включается.

Результаты и artifact доступны во вкладке `Actions` репозитория.

## Логи и диагностика

Логи запуска, остановки и результатов обработки выводятся в терминал сервера. Пользовательский текст в них не записывается.

- `/health` должен вернуть `{"status": "ok"}`.
- `/version` возвращает настроенную версию.
- `422` — проверьте текст и значение `limit`.
- `404` — проверьте адрес маршрута.
- `405` — проверьте HTTP-метод запроса.
- Ошибка импорта — проверьте окружение и установку зависимостей.
- Интерфейс не получает результаты — проверьте, запущен ли сервер, и открывайте страницу через `http://127.0.0.1:8000/`.
- Порт занят — используйте `python -m uvicorn app_final:app --port 8001` и откройте `http://127.0.0.1:8001/`.
